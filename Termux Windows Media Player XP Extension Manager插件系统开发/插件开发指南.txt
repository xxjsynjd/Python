================================================================================
TEMPXPEM 插件开发指南
(写给滤镜/场景开发者)
================================================================================

【前言】
你不需要懂 FFmpeg，不需要懂音视频混流，也不需要懂包管理器底层。
你只需要会写基础的 Python 和 Pygame，就能做出一个可以在“信息技术疑难解答媒体播放器”里运行的视觉特效。

================================================================================
一、 核心约定 (必须遵守)
================================================================================
1. 你的插件入口文件必须叫：wmpvisualizer.dll（虽然后缀是 dll，但里面是纯 Python 代码）。
2. 你的插件必须实现两个函数：audio_tick 和 video_render。
3. 你的插件必须有一个 twmpxpem-project.toml 配置文件，且必须写明 category（分类）。

================================================================================
二、 最小插件模板 (直接复制就能用)
================================================================================
在你的插件文件夹下，创建两个文件：

【文件 1: twmpxpem-project.toml】
----------------------------------------------------------------------
[project]
name = "my_first_filter"
version = "1.0.0"
category = "video-effects"
description = "我的第一个音视频可视化插件"
----------------------------------------------------------------------

【文件 2: wmpvisualizer.dll】
----------------------------------------------------------------------
import pygame
import math

# 全局状态（每次切片加载时都会全新初始化，无需手动清理）
_state = {}

def audio_tick(data, spectrum, dt):
    """
    【逻辑更新】接收音频数据，更新内部状态。
    参数:
      data     : 预留参数，目前传 None
      spectrum : 字典，包含 'bass'(低音能量) 和 'treble'(高音能量)，范围 0.0~1.0
      dt       : 帧间隔时间，固定为 1/30 秒
    """
    global _state
    if not _state:
        _state["radius"] = 50.0

    bass = spectrum.get("bass", 0.0)
    target = 50.0 + bass * 150.0
    _state["radius"] += (target - _state["radius"]) * 0.2

def video_render(screen, data, audio_data):
    """
    【画面渲染】在内存画布上绘制你的画面。
    参数:
      screen     : Pygame Surface 对象，尺寸就是视频分辨率（如 1280x720）
      data       : 预留参数，目前传 None
      audio_data : 与 audio_tick 中的 spectrum 相同
    """
    w, h = screen.get_size()
    radius = int(_state.get("radius", 50))
    pygame.draw.circle(screen, (0, 255, 255), (w // 2, h // 2), radius, 4)
----------------------------------------------------------------------

================================================================================
三、 打包与安装流程
================================================================================
1. 把上面两个文件放进一个文件夹，比如 my_first_filter/。
2. 在终端进入该文件夹的上一级目录。
3. 打包成 .wvwhl 包（本质上是 zip）：
   zip -r my_first_filter.wvwhl my_first_filter/*
4. 用包管理器安装：
   twmpxpem install my_first_filter.wvwhl
5. 运行引擎测试：
   wmpvisualizer1 -i 你的音频.mp3 -s my_first_filter -p video-effects -o 测试.mp4

================================================================================
四、 绘制 API 速查 (Pygame 常用函数)
================================================================================
你的 screen 就是一个 Pygame Surface，你可以直接调用 Pygame 所有绘制函数：

- 画圆：    pygame.draw.circle(screen, (R,G,B), (x, y), 半径, 线宽)
- 画线：    pygame.draw.line(screen, (R,G,B), (x1,y1), (x2,y2), 线宽)
- 画矩形：  pygame.draw.rect(screen, (R,G,B), (x, y, 宽, 高), 线宽)
- 画多边形：pygame.draw.polygon(screen, (R,G,B), [(x1,y1), (x2,y2), ...], 线宽)
- 画文字：  先 pygame.font.Font(字体路径, 字号).render("文字", True, (R,G,B))，
           再 screen.blit(文字Surface, (x, y))
- 贴图片：  用 pygame.image.load("图片路径")，然后 screen.blit(图片, (x, y))
- 半透明效果：用 pygame.Surface((w,h), pygame.SRCALPHA) 创建带透明通道的画布，
           在上面画图后，再用 screen.blit() 贴到主画布上。

================================================================================
五、 开发注意事项 (避坑指南)
================================================================================
1. 不要把耗时逻辑写在 video_render 里（比如网络请求、大文件读取），否则会导致渲染极慢。
2. 不要在插件里 print 大量日志，否则终端会被刷屏，影响进度条显示。
3. 每次随机蒙太奇切换插件时，引擎会重新 import 你的模块，所以全局变量 _state 会自动重置。如果你希望保留某些“跨切片状态”，可以写到文件里（不推荐）。
4. 务必在 toml 里写好 category！如果分类写错，单场景模式（-s）会强制报错。

================================================================================
六、 灵感：你可以做什么特效？
================================================================================
- 频谱柱状图（Bars Spectrum）
- 5.1 / 7.1 环绕声五边形/七边形矩阵
- 赛博朋克故障艺术（Glitch Art）
- 粒子引力场（Bass 爆发时粒子向中心坍缩）
- 示波器波形（用 pygame.draw.lines 画真实波形）
- 极简几何动画（旋转的五角星、脉冲圆环）

================================================================================
七、 遇到问题怎么办？
================================================================================
如果引擎报错“缺少 audio_tick 或 video_render 函数”，请检查你的 wmpvisualizer.dll 里是否
正确定义了这两个函数，并且缩进正确（必须是顶层函数，不要在 class 里）。
如果报错“分类不匹配”，请检查你的 twmpxpem-project.toml 里 category 字段是否和 -p 参数一致。
