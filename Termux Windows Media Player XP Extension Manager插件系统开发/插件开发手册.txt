================================================================================
TEMPXPEM 插件开发手册 (v1.0 - 底座封版版)
(适用于：信息技术疑难解答媒体播放器)
================================================================================

【前言】
底座引擎已经彻底封版。
你不需要懂 FFmpeg，不需要懂音视频混流，不需要懂包管理器底层逻辑。
你只需要会写 Python 和 Pygame，就能开发出在引擎里运行的视觉特效。

================================================================================
一、 你必须遵守的“插件契约”
================================================================================
1. 入口文件名必须叫：wmpvisualizer.dll（内容实际是纯 Python 代码）。
2. 必须实现两个函数：audio_tick 和 video_render。
3. 必须有一个 twmpxpem-project.toml，并且写明 category（分类）。

================================================================================
二、 引擎传给你的数据长什么样？
================================================================================
在你的 audio_tick 和 video_render 里，引擎会传给你一个名为 spectrum 的字典。
这就是你的“画笔和颜料”。它的结构如下：

{
    "bass": float,       # 低音能量 (0.0 ~ 1.0)，适合驱动底鼓、心跳、爆炸特效
    "treble": float,     # 高音能量 (0.0 ~ 1.0)，适合驱动电音嘶嘶声、闪光、粒子
    "channels": int,     # 当前音频的真实声道数 (2=立体声, 6=5.1, 8=7.1)
    "waves": {           # 每个声道的真实波形采样点 (每帧固定 128 个点)
        "ch0": [float, float, ...],  # 声道 0 (如左声道)
        "ch1": [float, float, ...],  # 声道 1 (如右声道)
        "ch2": [...],                # 声道 2 (如果是 5.1)
        # ...
    }
}

注意：waves 里的每个采样点在 -1.0 到 1.0 之间。0 是静音基准线。

三、 最小插件模板 (直接复制)
================================================================================

【文件 1: twmpxpem-project.toml】
----------------------------------------------------------------------
[project]
name = "my_custom_visual"
version = "1.0.0"
category = "video-effects"
description = "我的自定义视觉插件"
----------------------------------------------------------------------

【文件 2: wmpvisualizer.dll】
----------------------------------------------------------------------
import pygame

# 全局状态 (每次切片加载时会自动重置)
_state = {}

def audio_tick(data, spectrum, dt):
    """逻辑更新：在这里根据音频数据更新你的状态变量"""
    global _state
    if not _state:
        _state["scale"] = 1.0

    bass = spectrum.get("bass", 0.0)
    target_scale = 1.0 + bass * 2.0
    _state["scale"] += (target_scale - _state["scale"]) * 0.2


def video_render(screen, data, audio_data):
    """画面渲染：在这里把你的状态画到屏幕上"""
    w, h = screen.get_size()
    cx, cy = w // 2, h // 2

    channels = audio_data.get("channels", 2)
    waves = audio_data.get("waves", {})

    # 示例 1：根据 bass 画一个呼吸圆环
    scale = _state.get("scale", 1.0)
    pygame.draw.circle(screen, (255, 105, 180), (cx, cy), int(100 * scale), 4)

    # 示例 2：动态画出所有声道的真实波形 (S型曲线)
    colors = [(0,255,255), (255,0,255), (255,255,0), (0,255,0), (255,128,0), (128,0,255), (255,255,255), (128,128,128)]
    import math
    for i in range(channels):
        ch_data = waves.get(f"ch{i}", [])
        if len(ch_data) < 2: continue
        
        color = colors[i % len(colors)]
        angle = (2 * math.pi / channels) * i
        offset_x = math.cos(angle) * 100
        offset_y = math.sin(angle) * 100
        
        points = []
        for idx, sample in enumerate(ch_data):
            spread = idx * 3
            x = cx + offset_x + math.cos(angle) * spread
            y = cy + offset_y + math.sin(angle) * spread + (sample * 150)
            points.append((x, y))
        
        pygame.draw.lines(screen, color, False, points, 2)
----------------------------------------------------------------------

四、 打包与安装
================================================================================
1. 在你的插件文件夹（包含上面两个文件）的上一级目录执行：
   zip -r my_custom_visual.wvwhl my_custom_visual/*

2. 安装进沙盒：
   twmpxpem install my_custom_visual.wvwhl

3. 测试渲染：
   wmpvisualizer1 -i 你的音频.mp3 -s my_custom_visual -p video-effects -d 15 -o 测试.mp4

================================================================================
五、 Pygame 绘制 API 速查
================================================================================
- 画圆：    pygame.draw.circle(screen, (R,G,B), (x, y), 半径, 线宽)
- 画线：    pygame.draw.line(screen, (R,G,B), (x1,y1), (x2,y2), 线宽)
- 画折线：  pygame.draw.lines(screen, (R,G,B), False, [(x1,y1), (x2,y2)...], 线宽)
- 画矩形：  pygame.draw.rect(screen, (R,G,B), (x, y, 宽, 高), 线宽)
- 画多边形：pygame.draw.polygon(screen, (R,G,B), [(x1,y1)...], 线宽)
- 透明度：  用 pygame.Surface((w,h), pygame.SRCALPHA) 创建画布，
           在上面画半透明图形后，再 blit 到主屏幕。

================================================================================
六、 避坑指南 (非常重要)
================================================================================
1. 不要在 video_render 里做耗时操作（如加载文件、发网络请求），否则视频会卡死。
2. 不要在插件里写大量 print()，会刷爆终端。
3. 每次随机蒙太奇切换插件时，模块会被重新加载。全局变量 _state 会自动清空。
4. 你的分类（category）必须与 twmpxpem-project.toml 一致，否则引擎会拒绝加载你。
